# Política de Seguridad / Security Policy

## 🇪🇸 Español

### Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad en cualquier proyecto de Kittora (por ejemplo LiquidGlass), **no la reportes en un issue público**. En su lugar:

1. Contacta directamente a los mantenedores por [correo/canal privado — completar].
2. Incluye una descripción del problema, pasos para reproducirlo y el impacto potencial.
3. Te responderemos en un plazo razonable para confirmar recepción y coordinar una solución.

### Versiones soportadas

Como los proyectos están en fase alpha/beta, generalmente solo se da soporte de seguridad a la última versión publicada, salvo que se indique lo contrario en el repositorio específico.

### Buenas prácticas para usuarios

- Descarga siempre desde el repositorio oficial de Kittora, nunca de fuentes de terceros.
- Verifica los hashes de los releases cuando estén disponibles.

## 🇬🇧 English

### Reporting a vulnerability

If you find a security vulnerability in any Kittora project (e.g. LiquidGlass), **do not report it in a public issue**. Instead:

1. Contact the maintainers directly via [email/private channel — fill in].
2. Include a description of the issue, reproduction steps, and potential impact.
3. We'll respond within a reasonable timeframe to confirm receipt and coordinate a fix.

### Supported versions

As projects are in alpha/beta stage, security support generally covers only the latest published version, unless stated otherwise in the specific repository.

### Best practices for users

- Always download from the official Kittora repository, never from third-party sources.
- Verify release hashes when available.

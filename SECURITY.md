# Security Policy

## Reporting a vulnerability

If you find a security vulnerability in any Kittora project (e.g. LiquidGlass), **do not report it in a public issue**. Instead:

1. Contact the maintainers directly via [email/private channel — fill in].
2. Include a description of the issue, reproduction steps, and potential impact.
3. We'll respond within a reasonable timeframe to confirm receipt and coordinate a fix.

## Supported versions

As projects are in alpha/beta stage, security support generally covers only the latest published version, unless stated otherwise in the specific repository.

## Best practices for users

- Always download from the official Kittora repository, never from third-party sources.
- Verify release hashes when available.

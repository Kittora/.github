Kittora is an organization focused on building small, well-crafted tools for creators — no bloatware, no unnecessary telemetry, good UX, and attention to detail. Right now the focus is on multimedia (downloading, converting, editing), but the scope isn't limited to that.

## 📦 Projects

| Project | Description | Status |
|---|---|---|
| [**LiquidCat**](https://github.com/Kittora/LiquidCat) | Multimedia downloader and re-encoder powered by `yt-dlp` and `ffmpeg`, with a WebView2 interface | 🟡 Functional alpha |

## 🛠️ Common stack

Python · WebView2 · yt-dlp · ffmpeg

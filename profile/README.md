## 🇪🇸 Español

Kittora es una organización dedicada a construir herramientas pequeñas y bien hechas para creadores — sin bloatware, sin telemetría innecesaria, con buena interfaz y atención al detalle. Hoy el foco está en multimedia (descarga, conversión, edición), pero el alcance no se limita a eso.

### 📦 Proyectos

| Proyecto | Descripción | Estado |
|---|---|---|
| [**LiquidGlass**](https://github.com/Kittora/LiquidGlass) | Downloader y reencoder multimedia usando `yt-dlp` y `ffmpeg`, con interfaz en WebView2 | 🟡 Alpha funcional |

### 🛠️ Stack común

Python · WebView2 · yt-dlp · ffmpeg

## 🇬🇧 English

Kittora is an organization focused on building small, well-crafted tools for creators — no bloatware, no unnecessary telemetry, good UX, and attention to detail. Right now the focus is on multimedia (downloading, converting, editing), but the scope isn't limited to that.

### 📦 Projects

| Project | Description | Status |
|---|---|---|
| [**LiquidGlass**](https://github.com/Kittora/LiquidGlass) | Multimedia downloader and re-encoder powered by `yt-dlp` and `ffmpeg`, with a WebView2 interface | 🟡 Functional alpha |

### 🛠️ Common stack

Python · WebView2 · yt-dlp · ffmpeg
